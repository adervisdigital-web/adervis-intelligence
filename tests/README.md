# Проверки

Запускать после любой правки приложения, базы или серверной функции.

```
cd intel\tests
npm install      # один раз
npm test
```

Должно закончиться тремя строками `ALL PASSED`.

| Файл | Что проверяет | Как |
|---|---|---|
| `db.test.mjs` | таблицы, права доступа, журнал, каскадное удаление, счётчик расходов на ИИ | поднимает настоящий Postgres в памяти (PGlite) и прогоняет обе миграции |
| `prompt.test.mjs` | отбор фактов, запрет выдумок, разбор ответа модели | вызывает `compose.ts` напрямую |
| `ui.test.mjs` | вход, доступ, создание и правку, конфликт правок, перенос данных, обрыв связи, генерацию черновиков, телефон | открывает приложение в Chromium с подменённым сервером |

Настоящий Supabase для проверок не нужен: база поднимается локально, а сервер в
проверках интерфейса подменяется заглушкой. Скриншоты складываются в
`tests/screenshots`.

Проверки интерфейса берут стартовые данные из `local-0.3/adervis-seed.json`.
